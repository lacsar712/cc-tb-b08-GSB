# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

这是制茶审评，不是菜谱，也不是饮食记录。

## 日账折点专页

顶栏「日账折点」进入 `/ledger`：

- **现场日账**：按自然日汇总通过条数与不通过条数，并画出折点图；明细支持按结论筛选（全部 / 只看通过 / 只看不通过），筛选由服务端 SQL 计算，不在浏览器里藏行。
- **签发快照**：审评员可对某日签发快照，冻结当时的通过数、不通过数与命中编号集合；同日只能签发一次，签发后一律不可改动（没有任何更新/删除入口）。之后再交评只改现场日账，不影响已签发快照。
- 快照与现场日账在页面上并排展示，互不覆盖。
- 观察员能看日账与快照，不能签发，也改不了任何已持久化的筛选结果。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 顶栏进「日账折点」：今日汇总为通过 1、不通过 1；筛选「只看不通过」后明细只剩夏茶-C（服务端过滤）。
5. taster 签发今日快照后再交一笔通过：现场日账今日通过数变 2，快照仍是通过 1、编号集合不变。
6. observer 能看日账与快照，但看不到签发按钮，直接 POST 签发返回 403。
