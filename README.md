# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

顶栏「日账折点」进入日账专页：

- 现场日账按东八区自然日汇总通过 / 不通过条数及命中编号。结论筛选（全部 / 只看通过 / 只看不通过）由服务端在 SQL 层完成，不是浏览器藏行。
- 审评员可签发某日快照，冻结当时的通过数、不通过数与命中编号集合（`daily_snapshots` 表，按日唯一、不可覆盖）。快照页与现场日账并排展示。
- 签发后再交评只改现场日账，快照数字与编号集合一律不动；把现场筛成只看不通过也不会改掉快照里的通过编号。
- 观察员（observer）能看日账与快照、能切换筛选，但不能签发、不能交评（签发/提交返回 403）。

这是制茶审评，不是菜谱，也不是饮食记录。
